# API生成器使用文档

## 概述

API生成器是一个通用的工具，可以自动生成标准的CRUD（增删改查）接口，同时支持扩展特殊接口。

## 功能特性

- ✅ 自动生成标准的增删改查接口
- ✅ 支持自定义特殊接口
- ✅ 统一的命名规范
- ✅ 易于扩展和维护

## 标准接口

每个模型会自动生成以下接口：

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| `get{Model}List` | GET | `/baseUrl` | 获取列表 |
| `get{Model}Detail` | GET | `/baseUrl/:id` | 获取详情 |
| `create{Model}` | POST | `/baseUrl` | 创建 |
| `update{Model}` | PUT | `/baseUrl/:id` | 更新 |
| `delete{Model}` | DELETE | `/baseUrl/:id` | 删除 |
| `batchDelete{Model}` | DELETE | `/baseUrl` | 批量删除 |
| `get{Model}Page` | GET | `/baseUrl/page` | 分页查询 |
| `search{Model}` | GET | `/baseUrl/search` | 搜索 |

## 使用方法

### 1. 基本使用

```javascript
import { apiGenerator } from '@/request/api/apiGenerator.js'

// 注册一个新的模型
apiGenerator.registerModel('article', '/articles')

// 获取生成的API
const articleApi = apiGenerator.getModelApi('article')

// 使用API
articleApi.getArticleList({ page: 1, size: 10 })
  .then(res => console.log(res))

articleApi.createArticle({ title: '标题', content: '内容' })
  .then(res => console.log(res))
```

### 2. 添加自定义接口

```javascript
import { apiGenerator } from '@/request/api/apiGenerator.js'
import http from '@/request/api/http.js'

// 注册模型并添加自定义接口
apiGenerator.registerModel('article', '/articles', {
  // 自定义接口
  publishArticle: (id) => http.post(`/articles/${id}/publish`),
  getArticleComments: (id) => http.get(`/articles/${id}/comments`),
  addArticleComment: (id, data) => http.post(`/articles/${id}/comments`, data),
  updateArticleStatus: (id, status) => http.patch(`/articles/${id}/status`, { status }),
})
```

### 3. 在组件中使用

```javascript
import api from '@/request/api/api.js'

export default {
  methods: {
    // 获取用户列表
    async getUserList() {
      try {
        const res = await api.getUserList({ page: 1, size: 10 })
        this.userList = res.data
      } catch (error) {
        console.error('获取用户列表失败:', error)
      }
    },

    // 创建用户
    async createUser(userData) {
      try {
        const res = await api.createUser(userData)
        this.$message.success('创建成功')
        this.getUserList() // 刷新列表
      } catch (error) {
        console.error('创建用户失败:', error)
      }
    },

    // 使用特殊接口
    async getUserProfile(userId) {
      try {
        const res = await api.getUserProfile(userId)
        this.userProfile = res.data
      } catch (error) {
        console.error('获取用户资料失败:', error)
      }
    }
  }
}
```

## 预定义模型

系统已预定义了以下模型的API：

### 用户 (User)
- 基础CRUD接口
- 特殊接口：
  - `getUserProfile(id)` - 获取用户资料
  - `updateUserAvatar(id, data)` - 更新头像
  - `resetUserPassword(id, data)` - 重置密码

### 产品 (Product)
- 基础CRUD接口
- 特殊接口：
  - `getProductCategories()` - 获取产品分类
  - `updateProductStatus(id, status)` - 更新产品状态
  - `getProductInventory(id)` - 获取库存信息

### 订单 (Order)
- 基础CRUD接口
- 特殊接口：
  - `getOrderStatistics(params)` - 获取订单统计
  - `cancelOrder(id, reason)` - 取消订单
  - `confirmOrder(id)` - 确认订单

### 分类 (Category)
- 基础CRUD接口
- 特殊接口：
  - `getCategoryTree()` - 获取分类树
  - `moveCategory(id, parentId)` - 移动分类

## 扩展新模型

要添加新的模型，只需要在 `api.js` 中添加：

```javascript
// 在 api.js 中添加
apiGenerator.registerModel('yourModel', '/your-endpoint', {
  // 自定义接口
  yourCustomMethod: (params) => http.get('/your-endpoint/custom', params),
})

// 然后在 export default 中添加
export default {
  // ... 其他接口
  
  // 你的模型相关
  ...apiGenerator.getModelApi('yourModel'),
}
```

## 注意事项

1. 模型名称会自动首字母大写，如 `user` 会生成 `getUserList` 等方法
2. 自定义接口会与标准接口合并，如果有重名会覆盖标准接口
3. 所有接口都返回 Promise，可以使用 async/await 或 .then() 处理
4. 错误处理建议在业务代码中进行统一处理
